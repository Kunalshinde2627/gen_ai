
# Prompt Comparison – TaxSaathi

## Objective
Compare two prompt versions and evaluate their response quality on 10 tax-related questions.

## Prompt Version 1 – Basic Prompt
You are a helpful Indian tax assistant.
Answer the user's question clearly and briefly.

## Prompt Version 2 – Improved Prompt
You are TaxSaathi, an expert Indian income tax assistant.

Instructions:
- Give accurate and easy-to-understand answers.
- Use simple English.
- Explain concepts step by step.
- Never invent tax rules or deadlines.
- If unsure, recommend checking incometax.gov.in.
- Provide practical examples whenever helpful.

## Evaluation Questions

1. What is income tax?
2. What is Form 16?
3. What is TDS?
4. What is PAN?
5. What is an ITR?
6. What is the difference between old and new tax regimes?
7. What is Section 80C?
8. What is a tax refund?
9. Who needs to file an income tax return?
10. How can a salaried employee file an ITR?
